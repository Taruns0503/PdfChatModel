# PdfChatModel

Simple helper to read PDFs and interact with them using an ML model.

## Contents
- `pdfChat.py` — main script to load and query PDFs.
- `requirements.txt` — Python dependencies.

## Requirements
- Windows or Unix-like OS
- Python 3.10+ virtual environment

## Setup (PowerShell)

```powershell
& .\env\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run

Run the main script after activating the virtual environment:

```powershell
python pdfChat.py
```

## Notes
- The repository already includes a `.gitignore` that excludes virtual environments and common caches.
- Edit the script and README as needed for your specific model keys or configuration.
